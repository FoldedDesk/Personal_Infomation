科研 / 竞赛实践

单晶硅太阳能电池交互仿真实验 App

将太阳能电池实验从“记录读数”推进到“理解物理模型”：以单二极管等效电路为核心，实时计算工作点、仪表读数和曲线结果。

我负责的工作
  • 建立单晶硅太阳能电池模型，处理负载电阻、光照强度和串联电池数量对输出的影响。
  • 实现虚拟实验台、接线状态、数据采集、曲线绘制和导出流程。
  • 撰写研究报告草稿，解释 I-V、P-V、最大功率点和填充因数的物理含义。
项目亮点
  • 读数和曲线来自同一个物理方程，避免界面演示与模型结果脱节。
  • 支持实验一伏安特性、实验二光强响应和 LED 串并联应用拓展。
  • 面向教学场景，兼顾可操作性、可解释性和实验报告输出。

小程序 / 后端服务

浦舆寻小程序前后端

为公交与地铁车辆资料建立查询与维护系统，让小程序端能稳定获取实时数据，也让管理员能在线维护来源文件和用户反馈。

我负责的工作
  • 设计并实现 FastAPI + SQLite 后端，提供公交车牌、自编号、地铁车号和车体号查询接口。
  • 实现后台管理、Excel / JSON / SQLite 导入、数据导出、权限配置和地铁数据维护页面。
  • 为微信小程序补充地铁查询入口，复用历史、模糊查询条数、复制和无结果状态。
项目亮点
  • 处理车号前导零、模糊匹配、号段资料和多车体号等容易出错的数据规则。
  • 补齐用户纠错、催促、申诉和进度查询接口，形成面向真实用户的闭环。
  • 小程序公共接口无需登录，后台维护和导入编辑保持管理员权限隔离。

Web 小游戏

小小远行 · JustASmallJourney

一个轻量、慢节奏的朋友旅行世界：玩家照料小动物、准备行囊、等待旅行归来，并通过明信片、纪念品和偶遇形成长期收藏。

我负责的工作
  • 搭建 Vue 3 + Vite 前端与 FastAPI 后端，管理账号、存档、旅行结算和库存状态。
  • 设计食物、工具、信物、天气、种植、兑换、赠礼、偶遇和收藏图鉴等游戏循环。
  • 补充测试与内容文档，确保离线结算、奖励发放和并发约束不会破坏存档。
项目亮点
  • 包含 60 种食物、50 个目的地、100 种纪念品、20 种工具和隐藏搭配故事。
  • 旅行过程中不直接公开目的地，归来拆信时才揭晓，保留探索感。
  • 室内外场景、背包、小铺、日记和明信片共同组成完整的轻量社交体验。
