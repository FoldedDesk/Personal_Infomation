# Personal Information Website

这是一个用于个人展示的静态前端框架，适合展示上海杉达学院计算机科学与技术卓越班学生的个人简介、专业能力、项目作品、成长轨迹和联系方式。

## 如何预览

直接在浏览器打开 `index.html` 即可查看页面。

## 文件说明

- `index.html`：页面内容与结构
- `styles.css`：视觉样式与响应式布局
- `script.js`：移动端导航和页面细节交互

## 后续可替换的信息

- 姓名、头像或个人照片
- 个人简介
- 专业技能
- 项目作品与项目链接
- 学习经历、竞赛经历、证书
- 邮箱、GitHub、Gitee、微信等联系方式
